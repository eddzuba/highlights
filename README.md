# Веб-плеер волейбольных розыгрышей (YouTube IFrame API & Telegram WebApp)

Автономное статическое SPA-приложение (чистый HTML5, CSS3 и vanilla JavaScript без сборщиков) для хостинга на GitHub Pages и работы внутри Telegram WebApp / мобильных браузеров.

Приложение позволяет игрокам комфортно просматривать свои волейбольные розыгрыши из матча, переключаться между играми и делиться персональными ссылками.

---

## 1. Структура проекта

```text
fragments_pipeline/player_web_player/
├── index.html              # Полный автономный SPA (разметка, стили и JS)
├── README.md               # Документация и инструкции по интеграции
└── matches/
    ├── index.json          # Каталог доступных матчей для селектора
    ├── 2026-11-10.json     # Данные матча: YouTube videoId, игроки и таймкоды розыгрышей
    └── 2026-11-03.json     # Пример предыдущей игры
```

## 2. Формат данных (JSON контракт)

### 2.1. Каталог матчей (`matches/index.json`)
Список матчей, доступных для выбора в выпадающем списке `#matchSelect`. Первый матч в списке считается самым актуальным:

```json
[
  {
    "id": "2026-11-10",
    "title": "10.11.2026 — Финал осеннего кубка",
    "date": "2026-11-10"
  },
  {
    "id": "2026-11-03",
    "title": "03.11.2026 — Полуфинал",
    "date": "2026-11-03"
  }
]
```

### 2.2. Файл конкретного матча (`matches/<match_id>.json`)
Содержит ID видео на YouTube (`videoId`), словарь соответствия `"telegram_id": "Имя Игрока"` и массив таймкодов розыгрышей (`rallies`):

```json
{
  "id": "2026-11-10",
  "videoId": "dQw4w9WgXcQ",
  "title": "10.11.2026 — Финал осеннего кубка",
  "players": {
    "108421945": "Эдуард",
    "284719284": "Алексей",
    "591827401": "Дмитрий",
    "391820471": "Иван"
  },
  "rallies": [
    {
      "id": 1,
      "start": 10,
      "end": 25,
      "score": "1:0",
      "players": ["108421945", "284719284", "591827401"]
    },
    {
      "id": 2,
      "start": 30,
      "end": 48,
      "score": "1:1",
      "players": ["391820471", "108421945"]
    }
  ]
}
```

- `start` / `end`: секунды от начала видео.
- `score`: текущий счёт (опционально).
- `players`: список строковых Telegram ID игроков, участвовавших в этом розыгрыше.

## 3. Определение Telegram ID и синхронизация URL

1. **Приоритет Telegram ID (`tg_id`)**:
   - **URL query-параметр**: `?tg_id=108421945` (высший приоритет, позволяет открывать хайлайты любого игрока по ссылке).
   - **Telegram WebApp SDK**: если параметр в URL не передан, берётся `window.Telegram?.WebApp?.initDataUnsafe?.user?.id`.
2. **Параметр матча (`match`)**:
   - URL-параметр `?match=2026-11-10`.
   - Если отсутствует в URL — автоматически загружается первый матч из `matches/index.json`.
3. **Обновление состояния без перезагрузки страницы**:
   - При смене матча или игрока URL автоматически обновляется через `window.history.replaceState()`.
   - Кнопка **«🔗 Поделиться»** копирует готовую персональную ссылку в буфер обмена с виброоткликом (Telegram Haptic Feedback).
4. **Сохранение активного игрока при смене матча**:
   - Если игрок участвовал в новой выбранной игре, фильтр остаётся активным для него.
   - Если игрока в новой игре нет, селектор переключается в положение «Все игроки».

## 4. Возможности видеоплеера

- **YouTube IFrame API**: официальный плеер с автовоспроизведением и адаптивным соотношением 16:9 (`playsinline: 1`).
- **Надежный автопереход**:
  - Высокоточный таймер с интервалом 200 мс отслеживает текущее время (`getCurrentTime() >= rally.end`).
  - Дополнительный перехват события завершения отрезка `onStateChange === YT.PlayerState.ENDED`.
  - Защита от повторного/двойного переключения (`isTransitioning`).
- **Управление**:
  - Кнопки: «⏮ Назад», «Повторить ⟲», «Воспроизведение/Пауза ⏯», «Вперед ⏭».
  - Переключатель скорости видео: `1x`, `0.75x`, `0.5x`.
  - Горячие клавиши на ПК: Пробел (Пауза), Стрелки влево/вправо (Розыгрыш назад/вперед), R (Повторить розыгрыш).
- **Карточки розыгрышей**:
  - Отображают номер, счёт, таймкод и бейджи участников с читаемыми именами.
  - Имя выбранного игрока подсвечивается акцентным чипом.
  - Активный розыгрыш подсвечивается и плавно скроллится в зону видимости (`scrollIntoView`).

## 5. UI и адаптивность

- **Dark Theme**: основной фон `#0f0f12`, фон карточек `#1b1b22`, акцентный цвет `#3b82f6` / `#ff4757`.
- **Mobile-First**: все интерактивные элементы (селекторы, кнопки навигации) имеют высоту от 44px для комфортного нажатия на смартфонах.
- **Интеграция с Telegram WebApp**:
  - Вызов `Telegram.WebApp.ready()` и `Telegram.WebApp.expand()` на весь экран.
  - Синхронизация цветов шапки и фона приложения (`setHeaderColor`, `setBackgroundColor`).
  - Haptic-feedback при копировании ссылки.

## 6. Локальный запуск и тестирование

Для запуска достаточно любого статического веб-сервера (например, встроенного в Python):

```bash
# Перейдите в папку с плеером
cd fragments_pipeline/player_web_player

# Запустите локальный сервер
python -m http.server 8080
```

Откройте в браузере:
- Обычный режим: [http://localhost:8080/](http://localhost:8080/)
- С конкретным игроком (Эдуард): [http://localhost:8080/?tg_id=108421945](http://localhost:8080/?tg_id=108421945)
- С конкретным матчем и игроком: [http://localhost:8080/?match=2026-11-10&tg_id=108421945](http://localhost:8080/?match=2026-11-10&tg_id=108421945)

## 7. Развертывание на GitHub Pages

1. Разместите содержимое папки в репозитории GitHub (в корне репозитория или в ветке `gh-pages` / папке `/docs`).
2. В настройках репозитория: **Settings -> Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` (или `gh-pages`), папка `/` (root).
3. Приложение будет доступно по адресу вида: `https://<username>.github.io/<repo-name>/`.

---

## 8. Подключение к Telegram Bot

Для открытия внутри Telegram WebApp добавьте кнопку в вашего бота (например, на `aiogram` / `python-telegram-bot`):

```python
from aiogram.types import InlineKeyboardMarkup, InlineKeyboardButton, WebAppInfo

webapp_url = "https://<your-github-username>.github.io/<repo-name>/"

keyboard = InlineKeyboardMarkup(inline_keyboard=[
    [
        InlineKeyboardButton(
            text="🏐 Смотреть мои розыгрыши",
            web_app=WebAppInfo(url=webapp_url)
        )
    ]
])

# При клике внутри Telegram WebApp передастся ID пользователя,
# и плеер автоматически откроет только его розыгрыши!
```
